Full config reference
N_TRAJECTORIES 300
How many synthetic spiral trajectories exist in the dataset.
stage 01 · generate
T 1200
Timesteps per trajectory — sets input/output width (T·3) of the autoencoder.
stage 01 · generate
NOISE_SIGMA 0.6
Std dev of Gaussian noise added per (x,y,z) point. Higher = harder denoising task.
stage 02 · corrupt
NORMALIZE False
If true, scales each trajectory by its own max before encoding, then rescales the decoder output back.
stage 03 · normalize
TRAIN_SPLIT 0.6
Fraction of trajectories used to fit model weights.
stage 04 · split
VAL_SPLIT 0.2
Fraction used for model selection / early stopping. Remaining 0.2 is held out as test.
stage 04 · split
HIDDEN_DIM 64
Width of the single hidden layer in both encoder and decoder. Lower = leaner model.
stage 05/07 · encoder & decoder
EMBEDDING_SIZE 8
Width of the bottleneck — how much the 3600-dim input (T·3) is compressed to.
stage 06 · bottleneck
EPOCHS 100
Full passes over the training set.
stage 08 · train loop
BATCH_SIZE 32
Trajectories per gradient update.
stage 08 · train loop
LR 1e-3
Adam learning rate. Try 1e-4–1e-2 if loss stalls or diverges.
stage 08 · train loop
SEED 5
Seeds numpy + torch so runs are reproducible and comparable.
bookkeeping
SAMPLE_IDX 50
Which test-split trajectory gets plotted/animated in the per-run figures.
bookkeeping
Autoencoder shape: input (T·3) → HIDDEN_DIM → EMBEDDING_SIZE → HIDDEN_DIM → output (T·3), each hidden layer followed by ReLU. Loss is MSE between reconstructed and clean trajectories, held-out test MSE reported alongside the no-denoising baseline (≈ sigma²).
